# NoExitRooms · Frontend (web)

Web de NoExitRooms hecha con HTML, CSS y JavaScript. Todos los datos los pide a la API del backend.

## Carpetas

- `*.html`: las páginas de la web
- `css/`: estilos
- `js/api.js`: conexión con la API
- `js/ui.js`: funciones comunes de la interfaz
- `js/paginas/`: el código de cada página
- `img/`: imágenes y logos
