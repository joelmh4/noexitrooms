Sobre nosotros

Encerramos gente por diversión

NoExitRooms nace en Madrid con seis salas en las que el humor, el terror y un poco de mala leche conviven con enigmas de verdad. Nada de candados al azar: cada prueba cuenta parte de la historia.

El local

Una antigua imprenta de 400 m² en Madrid con seis salas insonorizadas y una zona de espera con juegos de mesa.

Las salas

Diseñadas y construidas por nosotros. Cada temporada renovamos al menos una.

Para todos

Tres salas accesibles en silla de ruedas y versiones para familias con niños.

Sobre el proyecto

Proyecto trimestral de DAW

Esta web es el proyecto trimestral del ciclo de Desarrollo de Aplicaciones Web. Une una web pública de escape rooms con un sistema de soporte por tickets con tres roles (cliente, agente y administrador).
